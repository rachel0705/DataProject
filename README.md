# 🎵 Music Recommendation System - Data Exploration & Processing

This project is a simplified academic system designed to process and explore music data from the [Million Song Subset](https://labrosa.ee.columbia.edu/millionsong/), extract useful insights, and prepare it for potential use in recommendation algorithms.

## 📂 Project Structure

Below is a list of all the key files and what each one does:

### 🧠 Core Scripts

- **`main.py`**  
  Walks through the dataset folders, finds `.h5` files, and prints out the internal keys of each file to understand their structure.

- **`metadata.py`**  
  Extracts basic metadata such as artist name and song title from a limited number of `.h5` files for preview and understanding.

- **`searchByName.py`**  
  Allows searching for songs or artists by name (partial matches accepted) from the `.h5` files. Useful for simulating a user query.

- **`dataCleansing.py`**  
  Loads all `.h5` files, extracts and cleans the data (fills nulls, decodes byte strings), and exports it to a `cleaned_music_data.csv` and `.h5` file.

- **`mongoDatabase.py`**  
  Reads the cleaned data and inserts it into a MongoDB database for potential use in a larger backend or API system.

### 🧪 Testing

- **`test_music_project.py`**  
  Contains unit tests for logic-based functions using Python's `unittest` framework.

- **`test_dataCleansing.py`**  
  Unit tests specifically written for testing the data cleaning functions.

### 📊 Data Visualization

- **`graphics.py`**  (inside "graficas_generadas" folder)
  Generates charts from the cleaned dataset, including:
  - Top 10 most frequent artists
  - Correlation heatmap

- **`more_graphics.py`**  (inside "more_charts" folder)
  Additional visualizations:
  - Top 10 albums with most songs
  - Boxplot of artist hotttnesss (for top 5 artists)
  - Histogram of artist familiarity
  - Scatter plot of familiarity vs hotttnesss

### 📄 Documentation & Reports

- **`Pruebas_Music_Project.pdf`**  
  Report describing the full test flow (end-to-end), data validation, and evaluation of data quality.

- **`Analisis_Visual_Musica.pdf`**  
  Report explaining the charts generated by `graphics.py`.

- **`Additional_Charts_Report.pdf`**  
  Report explaining the second set of charts from `more_graphics.py`.

- **`privacy policy music project.pdf`**  
  A document explaining how the project handles user data with privacy best practices.

- **`diagrama de gantt fase 3 big data.pdf`**  
  A gantt diagram to show the activities completed during the duration of the project.
  
- **`hipotesis fase 3 big data.pdf`**  
  The 5 hypotheses raised at the beginning of the project when it had an application focus.
  
## 🏗️ Infrastructure & Tools Used

| Tool / Library   | Purpose                                                                 |
|------------------|-------------------------------------------------------------------------|
| **Python 3.x**   | Main programming language                                                |
| **pandas**       | Data handling, manipulation and CSV export                              |
| **numpy**        | Numerical operations and handling missing data                          |
| **matplotlib**   | Data visualization                                                      |
| **seaborn**      | Enhanced statistical visualizations (heatmaps, boxplots, etc.)          |
| **h5py**         | Reading `.h5` HDF5 song files from the Million Song Subset              |
| **os**           | File system operations (e.g. folder creation, walking directories)      |
| **unittest**     | Writing and executing unit tests                                        |
| **pytest**       | Optional testing framework with HTML report support                     |
| **pymongo**      | Sending cleaned data into a MongoDB database                            |
